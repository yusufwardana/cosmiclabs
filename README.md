# CosmicLabs 🚀

AI Content Studio untuk membuat konten TikTok otomatis dengan bantuan Gemini API.

## Cara Jalankan di Lokal
```bash
npm install
npm run dev
```
Buka di browser: `http://localhost:3000`

## Deploy ke Vercel
1. Upload ke GitHub
2. Masuk ke https://vercel.com
3. Import repository ini
4. Tambahkan Environment Variable:
   ```
   NEXT_PUBLIC_GEMINI_API_KEY=your_api_key_here
   ```
5. Klik **Deploy**
